## What I learned
- Cybersecurity = protecting people, data and systems from internal and external threats.
- Security analyst duties: monitor and protect networks/systems, install prevention tools, run security audits, check for vulnerabilities.
- Playbook = a step-by-step guide for how to respond to a situation (e.g., a phishing incident).
- Key terms: compliance, security framework, security control, security posture, threat actor, internal threat, network security, cloud security.
- Transferable skills: communication, collaboration, analysis, problem solving.
- Technical skills: programming, SIEM tools, IDS, computer forensics, threat landscape, incident response.
- CompTIA = a certification body (Security+ is the one I may take later).
- PII = info that identifies a person (name, email, address).
- SPII = more sensitive PII (bank, medical, ID numbers); leaking it causes more harm.
